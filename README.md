## Project Description
This project implements a comprehensive database management system for Ercan Airport. The database stores and manages information about:
- Airlines and Airplanes
- Hangars and their history
- Employees (Technicians and Traffic Controllers)
- Tests and Test Events
- Flights, Gates, and Runways
- Passengers, Tickets, and Baggage

## Database Schema
The database consists of 20 tables with 19 relationships including:
- One-to-Many, One-to-One, and Many-to-Many relationships
- Primary keys, foreign keys, and check constraints

## How to Run
1. Open MySQL Workbench or any MySQL client
2. Run `DDL_ercan_airport_project.sql` to create the database and tables
3. Run `DML_sample_data_ercan_airport.sql` to insert sample data
4. Run `airport_management_queries.sql` to test the management queries

- Average test score per airplane
